ขีดดำ = ควรอยู่ตรงนี้ตามเวลาที่ผ่านไป ตามแผน (80% ขึ้นไป) เสี่ยง (60–79%) ช้ากว่าแผน (ต่ำกว่า 60%)

    จำนวนคลิปที่ลง วิวรวมของคลิปที่ลงในเดือน และ Top 5 คลิปวิวสูงสุด เทียบกับเดือนก่อน · ที่มา: รายคลิปจากไฟล์วิดีโอ TikTok และ Facebook API

    Objective & Key Result

    เทียบยอดสะสมกับเป้าทั้งปี สีสถานะดูจาก Pace (เร็วหรือช้ากว่าเวลาที่ผ่านไป) ข้อสังเกตระบบเขียนให้อัตโนมัติ ส่วน Monthly Update กับ Next Step ทีมเขียนเอง · ที่มา: ข้อมูลรายเดือนของทุกบัญชี เป้าและค่าปีก่อนจากหน้าตั้งค่า

    Video Analysis คลิปวิวสูงสุดและต่ำสุดของแต่ละบัญชี

    ระบบเลือกคลิปและสรุปตัวเลขให้ ทีมใส่ชื่อ Creator และเขียนบทวิเคราะห์ 4 ด้านเหมือนในสไลด์ · กรองประเภทคลิปได้หลายประเภทพร้อมกัน

    YouTube Content Performance

    ตัวเลขสำคัญของเดือนเทียบเดือนก่อน วิดีโอเด่น 3 อันดับ และข้อแนะนำ · ที่มา: YouTube API

    สถานะ YouTube Partner Program

    ระยะทางถึงเกณฑ์สร้างรายได้ เลือกสะสมชั่วโมงคลิปยาว หรือยอดดู Shorts อย่างใดอย่างหนึ่ง · ที่มา: YouTube API

    ส่งเข้าระบบจริง: ลากไฟล์มาวาง ตรวจผล แล้วกด บันทึกเข้าระบบ ตัวเลขทุกหน้าอัปเดตทันที (ใช้รหัสทีม)

    อัปโหลดข้อมูล TikTok

    Export ไฟล์จาก TikTok Studio แล้วลากมาวางพร้อมกันทั้งหมด ระบบแยกให้เองว่าไฟล์ไหนเป็นข้อมูลอะไร

    อัปโหลดไฟล์

    รองรับไฟล์ .csv หรือ .zip ที่ดาวน์โหลดจาก TikTok Studio: ภาพรวม (Overview), ผู้ติดตาม และวิดีโอ

    ข้อมูลของแต่ละบัญชี

    ระบบส่งอีเมลเตือนทุกวันที่ 3 ถ้ายังไม่มีไฟล์ของเดือนก่อน

    ไฟล์ที่ระบบรู้จัก

    • ภาพรวม (Overview) วิว, Profile Views, ไลก์, คอมเมนต์, แชร์ รายวัน
    • FollowerHistory ผู้ติดตามรวมรายวัน ใช้คำนวณ Net Follower
    • FollowerActivity, FollowerGender, FollowerTopTerritories เวลาที่ผู้ติดตามออนไลน์ เพศ และประเทศ
    • วิดีโอ รายคลิป ใช้ทำ Top Ranking และนับ Monthly Output

    ตั้งค่า

    เชื่อมต่อทุกบัญชีและตั้งค่าระบบได้จากหน้านี้ ไม่ต้องเปิดชีตหรือ Apps Script

    การเชื่อมต่อ

    ดึงข้อมูลอัตโนมัติทุกวันเวลา 06:00 น.

    YouTube Eloopเชื่อมต่อแล้วดึงสำเร็จล่าสุด 5 พ.ย. 06:02 · ข้อมูลถึง 3 พ.ย.
    YouTube Moovเชื่อมต่อแล้วดึงสำเร็จล่าสุด 5 พ.ย. 06:02 · ข้อมูลถึง 3 พ.ย.
    TikTok Eloop, TikTok Moovอัปโหลดไฟล์ไม่ต้องเชื่อมต่อ ดูสถานะได้ที่หน้าอัปโหลด TikTok

    ตั้งค่าระบบ

    ทำครั้งเดียว ใช้รหัสทีมป้องกันไม่ให้คนนอกแก้ข้อมูล

    กำลังโหลดสถานะจากระบบ…

    เป้าหมายและค่าปีก่อน · ปี 2026

    ตั้งครั้งเดียวต้นปี แก้ตัวเลขแล้วภาพรวม หน้าบัญชี และหน้าสรุปรายเดือนเปลี่ยนตามทันที ค่าปีก่อนใช้แสดงคำว่า "เดิม" ในสไลด์

    บัญชีKey Resultเป้าทั้งปีค่าปีก่อน

    ใส่รหัสทีม

    ต้องใช้รหัสทีมก่อนแก้ข้อมูลในระบบ

    สร้างสไลด์สรุปประจำเดือน

    ระบบคัดลอกสไลด์เทมเพลตของทีม (หน้าตาเดียวกับไฟล์ Content OKR เดิม) แล้วเติมตัวเลขและข้อความจากหน้าสรุปรายเดือนให้ประมาณ 16 หน้า

    1. ปก และ Update KPI & OKRชื่อเดือน และช่วงวันที่ของข้อมูล
    2. Short VDO แยกแบรนด์ (2 หน้า)จำนวนคลิป วิวรวม เทียบเดือนก่อน และ Top 5 TikTok กับ Facebook Reels
    3. OKR แยกแพลตฟอร์ม (3 หน้า)TikTok, Facebook, YouTube พร้อม % เทียบเป้า สีสถานะ และ Key Insights ที่ทีมเขียน
    4. Video Analysis (บัญชีละ 1 หน้า)คลิปวิวสูงสุดและต่ำสุด ตัวเลข และบทวิเคราะห์ 4 ด้าน
    5. YouTube Content Performance (2 หน้า)ตัวเลขสำคัญ วิดีโอเด่น 3 อันดับ และข้อแนะนำ
    6. สถานะ YouTube Partner Programระยะทางถึงเกณฑ์สร้างรายได้ของทั้ง 2 ช่อง
    7. ข้อสังเกตอัตโนมัติ
